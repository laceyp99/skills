# GitHub PR comments

Add GitHub PR comments only when the user explicitly asks to comment on the PR.

When commenting:

- Comment only on actionable issues, using the full Findings format including Necessity and Reproduction/evidence. Include concise expected-versus-observed proof or an explicit Not reproduced explanation. Link supporting artifacts only when accessible to the intended reviewers and authorized for publication; never post local filesystem links as shared evidence.
- Do not duplicate existing comments or unresolved threads.
- Prefer inline comments for line-specific findings.
- Use a general PR comment only for cross-cutting concerns.
- Summarize exactly what comments were added.

If line-specific commenting is not possible with available tools, report the blocker and provide suggested comment text instead of guessing.
