# HTML report

Perform the review and use `/html-communication` to create a local HTML report as the main reader-facing result. Use the Findings format, making severity, fix complexity, decision needs, review scope and limits, and the next action easy to inspect. Choose visuals or interaction to suit the reviewed change; do not impose a fixed layout. Keep GitHub comments or `review-findings.md` as the actionable record where applicable.

Deliver the checkpoint quiz as the report's baked section through `/checkpoint-quiz` report mode.

In chat, link the report and briefly state the review conclusion and next action; keep the detailed findings in the report.
